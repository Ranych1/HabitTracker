# HabitTracker

Веб-приложение для трекинга привычек и ежедневной статистики на Java 17, Spring Boot 3.2.5, H2 Database и HTML5 / CSS3 / Vanilla JS.

## Команда
- Алтунин К., Рыбкин А., Романов А. (группа 25ИП2Б)
- Преподаватель: Зупарова В. В.

## Запуск
- Приложение: mvn spring-boot:run (http://localhost:8080, демо-аккаунт: demo@kinlant.ru / 1234)
- Тесты: mvn test
